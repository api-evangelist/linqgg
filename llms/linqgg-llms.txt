# LinQ (Galactica Games, Inc. dba Toffee)

> LinQ is a wallet, payments and loyalty platform for game developers building
> loyalty programs, real-money gaming (RMG) and branded debit-card experiences.
> Games create a LinQ wallet account for each player, then deposit, withdraw,
> transfer and reconcile funds against internal game currencies. The public API
> is gRPC / Protocol Buffers, published on the Buf Schema Registry.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from
apis.yml and the artifacts in this repository. LinQ does not publish an
/llms.txt of its own (probed: 404 on linq.gg, docs.linq.gg, galactica.games,
services.galactica.games).

## Key facts

- Interface: gRPC with Protocol Buffers (proto3). No REST, OpenAPI, GraphQL or AsyncAPI.
- Contract: https://buf.build/linq/linq (public Buf Schema Registry module, MIT)
- Production host: services.galactica.games
- Stage host: services.stage.galactica.games
- Auth: opaque bearer tokens in gRPC `authorization` metadata. No OAuth, no scopes.
- Money: all amounts are integers in coins — divide by 100 before display.
- Idempotency: `idempotency_key` is a request-message field, not a header.
- Errors: native gRPC statuses. Business outcomes ride in-band on success responses.
- Events: none. Order completion is discovered by polling GetOrderStatus.

## Order status machine

pending -> awaiting -> processing -> accepted -> completed
Terminal failure states: declined, cancelled, terminated.
Order types: charge, entry_fee, prize, transfer.

## Constraints an agent must respect

- Eleven operations move real money. Always supply a stable idempotency_key on
  PutMoney, GetMoney and NewTransferOrder so a retry cannot double-spend.
- Check IsAccessAllowed (by IP) and IsOperationAllowed (by coordinates) before
  initiating any funds movement — access is gated by jurisdiction and sanctions.
- Anonymous profiles cannot transfer to the wallet or other games and are capped
  at a total deposit amount of 20.00. Use IsLimitReached to check headroom.
- Never route raw card data through a game backend; tokenization happens on device
  via the Unity SDK. Doing otherwise breaks the PCI DSS posture LinQ documents.
- Balances for games other than the calling game are never returned.
